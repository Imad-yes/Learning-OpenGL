# Learning-OpenGL
A repository for tracking my progress as I learn computer graphics with OpenGL following
the tutorial from learnopengl.com
I use the GLAD function loader

include/ directory contains necessary header files.
hello_triangle/ contains the two required source/library files: hello.cpp and glad.c as well
as the Makefile. 
Run the command >>make inside hello_triangle to compile the code. And run the ./main file to execute
the program.
